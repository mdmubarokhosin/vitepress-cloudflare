# What is VitePress?

**VitePress** হলো একটি static site generator (SSG) যা বিশেষভাবে ডকুমেন্টেশন ওয়েবসাইট তৈরির জন্য ডিজাইন করা। এটি VuePress-এর উত্তরসূরি, Vue.js এবং Vite-এর উপর নির্মিত, যা নাটকীয়ভাবে উন্নত পারফরম্যান্স প্রদান করে।

## মূল ফিচারস

VitePress সাধারণ Markdown ফাইলকে একটি দ্রুত, SEO-বান্ধব এবং সুন্দরভাবে থিমড ডকুমেন্টেশন ওয়েবসাইটে রূপান্তর করে। এর মূল সক্ষমতাগুলো হলো:

### ডিফল্টভাবে দ্রুত

VitePress এর বিল্ড টুল হিসেবে **Vite** ব্যবহার করে, যার মানে হলো:

- ডেভেলপমেন্টের সময় **তাৎক্ষণিক hot module replacement (HMR)**
- কোড স্প্লিটিং সহ **অপ্টিমাইজড প্রোডাকশন বিল্ড**
- প্রতিটি পৃষ্ঠার জন্য **Static HTML আউটপুট** — প্রাথমিক রেন্ডারের জন্য JavaScript এর প্রয়োজন নেই
- প্রোডাকশনে **১০০ms-এর কম পেজ লোড**

### Markdown এক্সটেনশন

VitePress শক্তিশালী এক্সটেনশন সহ স্ট্যান্ডার্ড Markdown উন্নত করে:

- **কোড গ্রুপ** — একাধিক ভাষা দেখানোর জন্য ট্যাবড কোড ব্লক
- **কাস্টম কন্টেইনার** — info, tip, warning, danger, এবং details ব্লক
- **ইমোজি সাপোর্ট** — markdown-এ সরাসরি ইমোজি ব্যবহার করুন
- **সূচি** — হেডিং থেকে স্বয়ংক্রিয়ভাবে তৈরি
- **GitHub-স্টাইল সতর্কতা** — `[!NOTE]`, `[!TIP]`, `[!WARNING]`, `[!CAUTION]`

```md
::: tip
This is a tip container
:::

::: warning
This is a warning
:::

::: danger
This is a danger alert
:::
```

### বিল্ট-ইন ফিচারস

VitePress ডকুমেন্টেশনের জন্য আপনার যা প্রয়োজন তা নিয়ে আসে:

- **গ্লোবাল সার্চ** — লোকাল সার্চ প্রোভাইডার (Algolia এর প্রয়োজন নেই)
- **ডার্ক/লাইট মোড** — বিল্ট-ইন অ্যাপিয়ারেন্স টগল
- **Internationalization (i18n)** — লোকেল রাউটিং সহ বহুভাষিক সাপোর্ট
- **রেসপন্সিভ ডিজাইন** — সমস্ত স্ক্রিন সাইজে কাজ করে
- **এডিটেবল লিংক** — "GitHub-এ এই পেজ এডিট করুন" বাটন
- **আগে/পরে নেভিগেশন** — স্বয়ংক্রিয় পেজ নেভিগেশন
- **ফুল-টেক্সট সার্চ** — ক্লায়েন্ট-সাইড সার্চ ইনডেক্সিং

### Vue-চালিত

যেহেতু VitePress Vue.js দিয়ে তৈরি, আপনি:

- আপনার markdown ফাইলের মধ্যে **Vue কম্পোনেন্ট** ব্যবহার করতে পারেন
- **কাস্টম থিম লেআউট** তৈরি করতে পারেন
- **ইন্টারেক্টিভ ডেমো** এবং লাইভ উদাহরণ যোগ করতে পারেন
- Vue-এর রিঅ্যাক্টিভিটি সিস্টেম দিয়ে **ডাইনামিক কন্টেন্ট** তৈরি করতে পারেন

:::

## রিয়েল-ওয়ার্ল্ড ব্যবহারের ক্ষেত্রে

VitePress বড় প্রজেক্টগুলো তাদের ডকুমেন্টেশনের জন্য ব্যবহার করে:

- **Vue.js** — অফিসিয়াল Vue ডকুমেন্টেশন সাইট
- **Vite** — Vite বিল্ড টুল ডকুমেন্টেশন
- **Pinia** — Vue state management লাইব্রেরি ডকস
- **Vitest** — টেস্টিং ফ্রেমওয়ার্ক ডকুমেন্টেশন

এই রিয়েল-ওয়ার্ল্ড উদাহরণগুলো প্রমাণ করে যে VitePress যেকোনো স্কেলের ডকুমেন্টেশন সাইট হ্যান্ডেল করতে পারে, ছোট প্রজেক্ট ডকস থেকে শুরু করে শত শত পৃষ্ঠার বড় ফ্রেমওয়ার্ক ডকুমেন্টেশন পর্যন্ত।
