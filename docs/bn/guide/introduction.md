# Introduction

**VitePress কোর্সে** স্বাগতম — VitePress ব্যবহার করে পেশাদার ডকুমেন্টেশন ওয়েবসাইট তৈরি করা এবং Cloudflare Pages-এ ডিপ্লয় করার জন্য আপনার সম্পূর্ণ গাইড।

## আপনি কী শিখবেন

এই কোর্সটি শূন্য থেকে সম্পূর্ণভাবে ডিপ্লয় করা ডকুমেন্টেশন ওয়েবসাইট পর্যন্ত যাওয়ার জন্য আপনার যা প্রয়োজন তা কভার করে। আপনি API ডকস, একটি নলেজ বেস, একটি টেকনিক্যাল ব্লগ, বা প্রোডাক্ট ডকুমেন্টেশন তৈরি করুন না কেন, VitePress এটি দ্রুত এবং সুন্দর করার জন্য টুল প্রদান করে।

### পূর্বশর্তাবলী

এই কোর্স শুরু করার আগে, আপনার নিম্নলিখিতগুলো থাকা উচিত:

- আপনার মেশিনে **Node.js 18+** ইনস্টল করা থাকা
- **HTML এবং Markdown** এর প্রাথমিক জ্ঞান
- একটি **GitHub অ্যাকাউন্ট** (বিনামূল্যে)
- একটি **Cloudflare অ্যাকাউন্ট** (বিনামূল্যে)

Vue.js বা অ্যাডভান্সড JavaScript জ্ঞানের প্রয়োজন নেই — VitePress আপনার জন্য জটিলতা সামলায়।

### VitePress কেন?

VitePress Vue.js এবং Vite-এর উপর নির্মিত, যা ডেভেলপমেন্ট এবং প্রোডাকশন উভয় ক্ষেত্রেই এটিকে অবিশ্বাস্যভাবে দ্রুত করে তোলে। এটি অফার করে:

- **অত্যন্ত দ্রুত বিল্ড** — Vite-এর অপ্টিমাইজড বান্ডলিং এর কারণে
- **Vue-চালিত কম্পোনেন্ট** — সহজেই ইন্টারেক্টিভ এলিমেন্ট যোগ করুন
- **Markdown এক্সটেনশন** — কোড গ্রুপ, কন্টেইনার, কাস্টম কম্পোনেন্ট
- **i18n সাপোর্ট** — বহুভাষিক সাইট বক্সের বাইরে
- **SEO বান্ধব** — সঠিক meta ট্যাগ সহ static HTML জেনারেশন
- **শুরু করতে জিরো কনফিগ** — শুধু ইনস্টল করুন এবং markdown লিখুন

::: tip Recommended
আপনি যদি এমন একটি ডকুমেন্টেশন সাইট চান যা ১০০ms-এর কম সময়ে লোড হয়, ডার্ক মোড সাপোর্ট করে, বিল্ট-ইন সার্চ আছে, এবং বিনামূল্যে ডিপ্লয় করা যায় — VitePress সেরা পছন্দ।
:::

### এই কোর্সটি কীভাবে ব্যবহার করবেন

প্রতিটি অধ্যায় পূর্ববর্তীটির উপর ভিত্তি করে তৈরি। আপনার নিজের মেশিনে ফাইল তৈরি করে এবং কমান্ড চালিয়ে অনুসরণ করুন। শেষে, আপনার একটি সম্পূর্ণ, প্রোডাকশন-রেডি ডকুমেন্টেশন সাইট থাকবে।

কোড উদাহরণগুলো **কপি-পেস্ট রেডি** করে ডিজাইন করা হয়েছে। এই কোর্সে দেখানো প্রতিটি কনফিগারেশন যেমন আছে তেমনিই কাজ করে এবং আপনার নিজস্ব প্রজেক্টের ভিত্তি হিসেবে ব্যবহার করা যেতে পারে।
